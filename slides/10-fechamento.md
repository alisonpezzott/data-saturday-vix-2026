# Quando um app vale a pena

::left::

#### Cinco perguntas, dois minutos

1. Depois de ver o número, a pessoa **age** ou só entende?
2. É uma tela de números ou um **produto** com estados e ciclo de vida?
3. O dado já existe rio acima ou **nasce** quando alguém clica?
4. Quem mantém isso em um ano **lê código**?
5. Muita gente lendo o mesmo número, ou **poucos** executando um processo caro?

::right::

#### O placar

- **Zero ou uma** resposta do lado app: é report — com translytical task flow se precisar do botão
- **Três ou mais**: você está fazendo produto, não dashboard
- Write-back sozinho não justifica app: a linha é **propriedade** do dado

# Para levar

<v-clicks>

- Fabric Apps é **backend as a service** dentro do Fabric; Rayfin é o SDK open source que o declara em código
- Duas formas: o app **dono** do dado (entities) ou **leitor** do modelo (DAX) — e a híbrida fecha o ciclo do planejamento
- O modelo semântico continua sendo a **única fonte de cálculo**; o app é apresentação
- O repositório ensina o **agente**: skills, MCP e doc travada na versão
- Preview honesto: região, SSO exclusivo, CU no SQL e na GraphQL, GA no fim do ano

</v-clicks>
